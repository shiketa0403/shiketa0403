|---|---|

| 組み合わせ割引 | 基本プラン・セレクト10・セレクト5・サッカーセットとの同時契約で**WOWOW分が2,200円**（-330円） |
| └ 基本プラン併用 | 3,960円＋2,200円＝6,160円（通常6,490円） |
| └ セレクト10併用 | 2,860円＋2,200円＝5,060円（通常5,390円） |
| └ セレクト5併用 | 1,980円＋2,200円＝4,180円（通常4,510円） |
| └ サッカーセット併用 | 2,480円＋2,200円＝4,680円（通常5,010円） |

| 現行キャンペーン | **視聴料2ヶ月半額（1,265円/月）・2026年8月1日〜9月30日契約分**。組み合わせ割引・複数台割引と併用可。基本プランも3ヶ月半額（8/1〜10/31）実施中 |

- 公式: WOWOW特設 https://www.skyperfectv.co.jp/program/st/campaign/wowow/ ／ 個別 https://www.skyperfectv.co.jp/plan/channel/basic/51M9801 ／ 組み合わせ割引一覧 https://www.skyperfectv.co.jp/plan/combination/basic
