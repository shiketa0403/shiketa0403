## 3. 法務・品質の制約（必ず守る）

1. **Googleマップのレビュー本文の転載はNG**（Maps Platform規約: 保存・キャッシュ禁止／投稿者の著作権）。評価点・件数（例: 3.3・90件）への言及は可
2. **口コミの創作はNG**（景表法ステマ規制）。実調査で確認できた声の「要旨」として書く。なければ「確認できませんでした」と正直に書く
3. **営業確認が取れない店を「営業中」として載せない**。現金化専門店は閉業サイクルが非常に速い（池袋では調査した専門店3件すべてが閉業・消滅・不存在だった）
4. 現金化はカード会員規約の禁止行為。注意喚起には日本クレジット協会の該当ページへ発リンク: https://www.j-credit.or.jp/customer/attention/attention_05.html （target="_blank" rel="noopener"）
5. 競合サイトの文章・比較表の転載NG。事実データ（住所等）は公式・Placesから取得済みのものを使う

## 8. 技術ノウハウ（ハマった所と回避策）

1. **現金化専門店はGoogleビジネス未登録が常態** → Placesの営業判定は金券ショップ等の「登録店」にしか効かない。専門店の生存判定は「公式サイトのDNS/HTTP生存＋媒体記載の突き合わせ」で行う（関東ギフトのDNS死亡はこれで検知）
2. **金券ショップ（チェーン）はPlacesで名称類似度1.0の一発一致** → データ自動化と相性が良い。類似度1.0未満は偽陽性あり（寿チケット→アクセスチケット誤マッチの実例）。0.9未満は目視確認
3. **Googleマップ埋め込みはAPIキー不要**: `<iframe src="https://maps.google.com/maps?q={緯度},{経度}&z=17&output=embed" width="100%" height="300" style="border:0;" loading="lazy"></iframe>`
4. **WPメディアアップロードは日本語ファイル名NG**（Content-Dispositionヘッダーがlatin-1でUnicodeEncodeError）→ ASCII名にリネームしてから送る（genkinka_publish.pyに実装済み）
5. **ヘテムルのSiteGuard（WAF）がアップロードを単発403で弾くことがある** → 数秒待ってリトライで通る（実装済み）
6. **civichat.jp は実はXserver**（PTR: sv10368.xserver.jp・agriwarriorsと同居）。現在GitHub ActionsからのREST接続がタイムアウト/403で失敗する（7/17までは成功実績あり）→ ASP記事パイプライン再開時に要調査。**本プロジェクト（ヘテムル）とは無関係**
7. claude.ai/codeのリモートセッションは外部HTTPSが許可リスト制でWPへ直接投稿不可 → ローカルセッション or GitHub Actions経由が必要（今回Actions経由を整備済み）
8. Places APIキーの作り方・制限設定は完了済み（Google Cloudプロジェクト`local-genkinka`・APIの制限=Places API (New)のみ・アプリ制限なし）

## 9. 他地域への展開手順（確立済みフロー）

1. GitHub Actions「**Genkinka Area**」を実行（例: area_ja=`新宿`, slug=`shinjuku`, ブランチ=`claude/auto-post-pipeline-new-site-b8RPi`）→ `master_shinjuku.csv`＋裏取り結果＋スクショ＋公式本文が自動生成・コミットされる

3. 記事執筆（ローカルチャット）→ `local-genkinka/articles/{slug}.html` に保存
4. 投稿: ローカル直接（§7）またはActions「Genkinka Post」
